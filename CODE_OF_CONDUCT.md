# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, give constructive feedback, and no harassment of any kind.

Report unacceptable behavior privately to the maintainer through
[GitHub private vulnerability reporting / contact options](https://github.com/gpont) or by opening an issue
asking for a private channel. Reports are handled confidentially.
