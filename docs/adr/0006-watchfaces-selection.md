# 0006. Watch face set

Status: accepted, 2026-11-11; trimmed by ADR 0007.

## Context
M1.5: a prototype gallery of 10 face concepts was built before the firmware to choose styles and fonts.

## Decision
- Implement all concepts first, then remove the ones that do not work on the wrist. Final set (ADR 0007):
  Big digits · Game Boy · Dashboard · Analog · Terminal · 90s LCD · Word clock.
- Each face is a separate module `src/ui/faces/<id>` so removing one is trivial (delete the file and its registry line).

## Fonts
OFL fonts from Google Fonts: Oswald SemiBold, Inter, JetBrains Mono, Unbounded, Press Start 2P (+ Noto Emoji
later). Big sizes (≥ 40 px) contain digits and `:` only; small sizes contain Latin + Cyrillic + digits + needed
symbols. Generated by `firmware/tools/fonts/gen.sh`.

## Known trade-offs
- Word clock: 5-minute precision.
- Analog: hands may cover the sub-dials in some positions (sub-dials are drawn below the hands).
